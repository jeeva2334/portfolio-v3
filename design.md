# Design System

## Typography
- **Primary Font**: Custom typeface / system-ui
- **Weights**: 400 (Regular), 500 (Medium), 600 (Semibold)
- **Hierarchy**:
  - Headings (`h1`, `h2`): Large, tracked slightly tighter.
  - Body copy: Highly legible, generous line height (1.6).

## Colors

### Light Mode
- Background: `#f4f4ef` (Warm off-white)
- Text: `#0a0a0a` (Near black)
- Accents: Subdued borders, dark interactive states.

### Dark Mode
- Background: `#0a0a0a` (Near black)
- Text: `#f4f4ef` (Warm off-white)
- Accents: Light interactive states, transparent overlay borders.

## Spacing & Layout
- A fluid layout with max-width wrappers (`.shell`).
- Generous whitespace between sections (`.section`).

## Interactions & Animation
- Subtle reveal animations.
- Smooth transitions for hover states on links and buttons.
- Reduced motion support.

## Core Tenets
- **Less, but better**: Strip away unnecessary elements until only what is essential remains. Every pixel must earn its place on the screen.
- **Function-Driven**: Identify the most direct, frictionless interaction models that allow users to accomplish their goals.
